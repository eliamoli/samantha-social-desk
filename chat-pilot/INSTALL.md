# Samantha Social Desk 0.4.0
One extension inside ordinary Claude Desktop Chat. No separate app, browser window, terminal, account connection, or API key. This build cannot create a real draft, schedule, or publish.

1. On the Mac in Claude Desktop, go to **Settings → Desktop app → Extensions → Advanced settings → Install Extension**, and select the 0.4.0 MCPB. If 0.3.0 is installed, update or replace that extension (same extension ID); leave 0.2.0 off while testing if it is also installed. Do not bypass an organizational block on unsigned extensions. Default: **off** (review only), no local folder, optional approval probe off.
2. Start a new ordinary Chat. Ask: **“Run review_samantha_mock_reel. Show the cover, caption and Halifax time. Don’t save a draft.”** Expect a sample cover and caption, Halifax time, and two synthetic destinations. If the cover does not appear inline, open the tool result in the same Chat. If it is still missing, return the app version and exact error.
3. Optional real-file review: select one local approved folder in the extension settings. It must hold the exact MP4, 1080×1920 PNG and matching small JSON manifest named as documented below. Ask **“Run review_samantha_local_reel for SJ-W03-R1”** (substitute your approved ID). This reads locally and shares the exact caption, cover and file metadata with Claude. Do not enable the folder for confidential content you do not want Claude to see. It never sends video bytes or supports path browsing or drafting real assets.
4. Optional mock rehearsal: change **Offline pilot mode** to **mock**, open ordinary Chat and rerun the synthetic review. Type one exact target confirmation shown; ask Claude to save a mock draft for that target. Expect **MOCK VERIFIED DRAFT • NO EXTERNAL ACTION**. Ask again to see duplicate prevention. Return mode to **off**. The visible rehearsal phrase is not authority for real writes.
5. Optional native check: set **Optional native approval probe** to **on** and ask **“Run probe_samantha_native_approval; use only the native form.”** It uses synthetic material; it does not create a draft or change permissions. A real test form must be interactive and show the exact action, not an assistant message. If unsupported, decline/cancel or switch off; this is not required to use review/mock.

Example for local review: SJ-W03-R1.json contains {"contentId":"SJ-W03-R1","revision":1,"caption":"Approved caption"}. Pair it with SJ-W03-R1-v1.mp4 and SJ-W03-R1-v1.png in that selected folder. Every correction gets a new revision. Keep only approved client assets there.
