# Samantha Social Desk v0.3: Mac Chat test
Preview and draft workflow test only. It never contacts Zernio, accepts private assets or credentials, or schedules/publishes. It displays a generated example, and mock drafts stay on this Mac. This candidate installs as a separate extension named **Samantha Social Desk Chat Pilot** so the verified v0.2 files remain intact.

1. In Claude Desktop on your Mac, install the supplied local MCPB under Settings → Extensions. If local unsigned extensions are disallowed, stop. Keep **Offline pilot mode** set to **off**. In a new ordinary **Chat** (not Cowork), ask: “Run review_samantha_mock_reel. Show the cover and exact caption, Halifax time, and both destinations here. Do not create a draft.” If a prompt picker exists, the review_samantha_mock prompt is the equivalent.
2. Record whether the review tool runs and whether the cream/maroon cover and text appear in the chat itself. Expect the synthetic MP4/PNG names and hashes, Friday Dec 4 at 10:30 a.m. Halifax / 14:30 UTC, and synthetic Instagram/Facebook targets. If the image isn't inline, check whether the tool result in that same chat shows it; text-only fallback is supported. If both image routes are absent, record that as a failed image acceptance test. Do not use a separate application.
3. If preview appears, temporarily set the extension's **Offline pilot mode** to **mock**, then open a new ordinary Chat. Start with preview again and ask it not to save anything until you confirm. Select “ask every time” for the draft tool if Claude offers permissions. Type one target's exact mock confirmation shown by the review (the tool adapter also checks the full review binding). Expected output: **MOCK VERIFIED DRAFT • NO EXTERNAL ACTION**, that exact target, its synthetic draft ID, and matching video/cover readback. Ask it again to save to the same target: it should refuse a duplicate. Repeat the intentionally distinct destination if desired.
4. Optional recovery test: temporarily set **mock-timeout** (isolated fixture state) and use the same confirmation steps. The mock will report a timeout after recording the synthetic draft. Do not repeat create. Restart Claude, open normal Chat, redo preview, then ask to reconcile rather than create. Expected: same local draft verified; nothing external happened.
5. Set mode back to **off**. Report Claude Desktop version, macOS version, whether cover appeared inline or in the tool result, mock verification result, and any exact technical error. Do not send a key or any client media.

The mock confirmation text is visible to the model. It demonstrates the intended interaction and data binding only; it is not proof that an assistant can't supply the words itself. Do not enable real writes until a separate trusted human authorization boundary is identified and verified for ordinary Chat, exact account and credential access are separately approved, and one separately authorized live-draft acceptance test is ready.
