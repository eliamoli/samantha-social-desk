# Samantha Social Desk 0.5.0

Local build only: `dist/samantha-social-desk-0.5.0.mcpb` and its adjacent SHA-256 file. No release has been published.

See [installation](../chat-pilot/INSTALL.md) and [approved transfer setup/usage](../TRANSFER.md).

Transfer defaults off. Preview remains available. This version transfers paired MP4/PNG files to temporary media storage, with durable receipts and a separate internal cover-payload assembler. It does not create drafts, attach covers to live drafts, schedule, publish or complete an older browser upload link.

The bundle is tested through extracted stdio with mocked HTTP on Windows. Actual Mac installation, Drive sync, credential storage, native approval rendering and live storage/cover display remain unverified.
